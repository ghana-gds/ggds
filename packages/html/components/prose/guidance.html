Styles for text from a content management system.

When to use

  • Around HTML written in a content management system.

When not to use

  • Around GGDS components. They have their own styles.

How to use

  • Wrap the content in ggds-prose.
  • Clean the HTML before you show it. GGDS only styles it; your website must remove unsafe code first.
  • Wrap tables in ggds-table-wrap.

Accessibility

  • Headings must go in order (h2, then h3), so screen reader users can move through the page.
