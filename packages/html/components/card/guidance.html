A box that sums up a page, service or document and links to it.

When to use

  • For a set of links to pages of a similar kind, such as services.

When not to use

  • For a single link in text. Use a normal link.
  • For long text.

How to use

  • Give each card a heading that is the link, and one short sentence below it.
  • Put cards in a ggds-card-grid: one column on phones, two on tablets, three on wide screens (ggds-card-grid--4 for four).
  • For a list of institutions, use ggds-card--institution with data-ggds-theme: logo, names, what it does, up to two common tasks, and a line in its colour.

Accessibility

  • Each card is one link for screen readers. Task links inside institution cards stay separate links.
