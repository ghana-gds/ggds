A box that sums up a page, service or document and links to it.

When to use

  • For a set of links to pages of a similar kind, such as services.

When not to use

  • For a single link in text. Use a normal link.
  • For long text.

How to use

  • Give each card a heading that is the link, and one short sentence below it.
  • Put cards in a ggds-card-grid: one column on phones, two on tablets, three on wide screens (ggds-card-grid--4 for four).
  • For a page of services or topics, such as a homepage's "Popular services", add an icon: ggds-card--icon, with a GGDS icon in <span class="ggds-card__icon"> before the heading. Pick an icon that shows what the card is about, use a different one on each card, and keep the words: the icon only helps people scan.
  • For a list of institutions, use ggds-card--institution with data-ggds-theme: logo, names, what it does, up to two common tasks, and a line in its colour.

Accessibility

What GGDS does

  • The whole card is clickable, but screen readers hear it as one link: its heading.
  • The focus ring goes round the whole card, and task links in institution cards stay separate links.

What you need to do

  • Make the card's heading a real heading at the right level, with the link inside it.
  • Write link text that makes sense on its own, because people often list a page's links.
