Links to the same page in other languages, each named in its own language.

When to use

  • When the page is published in more than one language: English and Twi, Ewe, Ga, Hausa or Dagbani, for example.

When not to use

  • When only some pages are translated: link to the translated page from the text instead, and say which language it is in.
  • With automatic translation that no speaker has checked. Government information must be accurate in every language it is published in.

How to use

  • Put it at the top of every page, above or in the header, in the same place on every page.
  • Name each language in that language ("Eʋegbe", not "Ewe"), so people who do not read English can find theirs.
  • Link each language to the same page in that language, not to the homepage.
  • Set <html lang> to the page's language on every page, and lang on any passage in another language.
  • GGDS's own text, such as "Skip to main content" and "There is a problem", comes in each language from GGDS, as far as speakers have translated it: see Languages in the developers' guide. Until then it is shown in English.
  • The names of the languages GGDS lists have not yet been checked by speakers. Check them with a speaker before you publish.

Accessibility

What GGDS does

  • Each link has lang, so a screen reader reads the language's name in that language, and hreflang.
  • The current language is bold, not a link style, and is announced as current (aria-current="true").
  • Every link is at least 44px tall.

What you need to do

  • Set lang on the page, so screen readers and translation tools use the right language (WCAG 3.1.1).
  • Do not use flags for languages: a flag is a country, not a language, and Ghana has many languages.
