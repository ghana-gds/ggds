"On this page": links to the sections of a long page, so people can go straight to the part they need.

When to use

  • On a page with three or more sections under <h2> headings, such as guidance or a service's rules.

When not to use

  • On a short page that fits on a phone screen or two.
  • To link to other pages: use side navigation.

How to use

  • Put it after the page's heading and introduction, before the first section.
  • Link to each <h2> by its id, with the heading's own words.
  • Keep it in the same order as the page.

Accessibility

What GGDS does

  • The list is a navigation landmark named by its heading, so screen reader users can find it.
  • The dash before each link is drawn and not read out.

What you need to do

  • Give every heading it links to a unique id, and keep the links working when a heading's words change.
  • If there is more than one contents list on a page, give each a different id for its title.
