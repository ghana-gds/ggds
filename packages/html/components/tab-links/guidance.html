Links that look like tabs, for moving between views of the same section.

When to use

  • For views of one list, such as "News", "Notices" and "Events".

When not to use

  • For content that should all be on one page. Use headings.
  • As the main navigation. Use the header.

How to use

  • Each tab is a normal link to its own page, so it works without JavaScript and can be bookmarked.
  • Mark the current tab with aria-current="page".

Accessibility

  • Do not add ARIA tab roles. These are links and should be announced as links.
