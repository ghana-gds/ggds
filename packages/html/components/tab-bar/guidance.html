Home, up to three main sections and Search, fixed to the bottom of the screen on phones.

When to use

  • On every page, together with the header. It only shows on phones.

When not to use

  • On wider screens: it hides itself there, and the header shows the sections.
  • For more than five links.

How to use

  • Always start with Home and end with Search.
  • Choose the three sections people use most. If unsure, the first three of: Agencies, Services, Complaints, Laws, Data, News, About.
  • Put it after the footer. The footer then leaves room so nothing is hidden behind the tab bar.

Do

  • Use the same tabs on every page.

Don't

  • Use icons without labels.

Accessibility

  • Every tab has a visible label as well as its icon.
  • Mark the section the visitor is in with aria-current="page".
