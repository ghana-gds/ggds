One box for a code people receive by SMS or email, which their phone can fill in for them.

When to use

  • To check a phone number or email address, or as the second step of signing in.

When not to use

  • For a mobile money PIN or a bank card's security code: people enter those on their phone or with their bank, never on a government website.

How to use

  • Use one box, not one box per digit: separate boxes break pasting, phones' automatic filling and screen readers.
  • Set autocomplete="one-time-code", inputmode="numeric" and class="ggds-input ggds-input--code". Do not use type="number": it drops leading zeros.
  • Say where the code went and how long it lasts in the hint: "We sent a 6-digit code to 024 *** 4567. It expires in 10 minutes."
  • Accept the code with spaces or dashes, and remove them before you check it.
  • Under the field, link to "Send a new code", and to another way to prove who they are, such as by email.
  • Say what went wrong, as in the second example: "The code is not right" or "The code has expired. Send a new code".

Accessibility

What GGDS does

  • The box is wide enough for the code, with spaced figures that are easy to check.

What you need to do

  • Give people enough time, and a way to get a new code (WCAG 2.2.1, timing adjustable).
  • Let them paste the code and let the phone fill it in (WCAG 3.3.8).
