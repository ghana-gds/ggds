Asks people before setting cookies the website does not need to work, such as analytics, and remembers their choice.

When to use

  • Only when the website wants to set cookies it does not need to work, such as analytics or video from another website.

When not to use

  • When the website uses only essential cookies, such as to remember a form's answers or keep people signed in. The best government website needs no cookie banner: measure visits on the server, without cookies, where you can.

How to use

  • Put it first in <body>, before the skip link, on every page until the person chooses.
  • Set no analytics cookie, and load no analytics, until the person accepts.
  • Give both choices the same button style and the same place, so neither is easier to press. Rejecting must be as easy as accepting.
  • The buttons send a form to your website, which remembers the choice in an essential cookie and shows the page again with the confirmation, then nothing once people hide it. No JavaScript is needed.
  • Link "View cookies" to a page that lists every cookie, what it is for and how long it lasts, where people can change their choice at any time.
  • Follow the Data Protection Act, 2012 (Act 843) and any guidance from the Data Protection Commission.

Accessibility

What GGDS does

  • It is a named region with a heading, so screen reader users know what it is.
  • It sits in the page, not over it: it never hides the content or traps the keyboard.

What you need to do

  • After a choice, show the confirmation in the same place, so people know it worked.
  • Do not move focus into the banner when the page loads.
