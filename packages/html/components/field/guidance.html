A single form question with a label, an optional hint and an error message.

When to use

  • To ask one question with a typed or chosen answer.

When not to use

  • For a choice from a short list. Use radios or checkboxes.

How to use

  • Every field has a visible label.
  • Put extra help in a hint under the label, and connect it with aria-describedby.
  • On error: add ggds-field--error, an error message starting with a hidden "Error:", and aria-invalid="true" on the input. Also list it in the error summary.
  • Use autocomplete for personal details such as name, phone and email.

Do

  • Say how to fix an error: "Enter your phone number".
  • Size the input to the answer: short for a code, long for a name.

Don't

  • Use placeholder text instead of a label.
  • Write "Invalid input".

Accessibility

  • Text is at least 16px, so phones do not zoom in.
