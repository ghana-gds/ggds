Buttons do things: submit a form, save, continue.

When to use

  • For actions.

When not to use

  • For links to other pages, except one link that starts a task ("Start now").

How to use

  • Use one main (primary) button per page. Use secondary and quiet buttons for other actions, and the warning style only for actions that delete something.

Do

  • Say what will happen: "Send complaint".

Don't

  • Write "Submit" or "Click here".
  • Put two primary buttons side by side.

Accessibility

  • Buttons are at least 44px tall.
