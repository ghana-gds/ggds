A link to the previous page of a task, for when the browser's back button might not take people there.

When to use

  • On the question pages of a form or service, where going back keeps people's answers.
  • After a page that a form sent people to, where the browser's back button would send the form again.

When not to use

  • On information pages. Use breadcrumbs, which show where the page sits.
  • With breadcrumbs on the same page: use one or the other.

How to use

  • Put it at the top of the main content, before the heading.
  • Link to the previous page itself, with its answers, not to the start of the task.
  • Keep the word "Back". Only change it when "Back" would be unclear, such as "Back to your applications".

Accessibility

What GGDS does

  • The arrow is drawn with CSS and is not read out; the link says "Back".
  • The link is at least 44px tall.

What you need to do

  • Make it a real link with an href, not a script that calls history.back(), so it works without JavaScript and can be opened in a new tab.
