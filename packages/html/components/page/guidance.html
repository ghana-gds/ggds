How the parts of a page fit together, in the same order on every government website.

When to use

  • As the starting point for every page.

When not to use

  • Changing the order of the parts. People rely on finding them in the same place.

How to use

  1. Skip link
  2. Government website banner
  3. Header
  4. Main content, starting with breadcrumbs on inner pages or the hero on the homepage
  5. Footer
  6. Tab bar (phones only)

Accessibility

What GGDS does

  • The page parts are landmarks in the expected order: banner, navigation, main content, footer.
  • Every part fits a 320px screen and works when text is enlarged.
  • The focus style is the same everywhere: a gold ring with a dark band inside it.

What you need to do

  • Set the language: <html lang="en-GB">, and lang on any passage in another language.
  • Use one <h1>, at the start of the main content, and give every page a unique <title>.
  • Allow zooming: never add maximum-scale or user-scalable=no to the viewport.
