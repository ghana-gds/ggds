A small picture next to words, to help people find and recognise things quickly.

GGDS has its own set of icons for government services, @ggds/icons. See all the icons, with what each one is for.

When to use

  • To help people scan a list of services, links or actions and find the one they want.
  • For a common action whose icon most people already know: download, print, search, menu.
  • To show the type of a link: a file to download, a website outside government, a phone number.

When not to use

  • On its own, without words. People guess the meaning of an icon differently, and many will not guess at all.
  • To decorate a page or fill space. Every icon is one more thing to look at.
  • For a status. Use a tag or a notice, which say it in words.

How to use

  • Put the icon before the words, or after them for "next" and "continue" arrows. Wrap both in ggds-with-icon so they line up.
  • Use the same icon for the same thing everywhere on your website, and only for that thing.
  • Use the default size next to body text, ggds-icon--sm next to small text, and ggds-icon--xl above a card's heading.
  • Do not change the stroke or colour of one icon: they are drawn to look like a set.
  • If GGDS has no icon for what you need, use words alone and ask for one. Do not mix in icons from other sets.

Adding icons to your website

With npm

Import only the icons you use: your bundler leaves out the rest.

import { download, svg } from '@ggds/icons';

element.innerHTML = svg(download) + '<span>Download the form</span>';

Astro, the documentation and other templates that pick icons by name can use icon(name) from @ggds/icons/all. In Django use {% ggds_icon "download" %}; in the WordPress theme, ggds_icon( 'download' ).

Without npm

The GGDS download has every icon in ggds/icons/. Either copy the SVG of one icon from icons/svg/ into your page, with class="ggds-icon" aria-hidden="true" focusable="false", or point to the sprite, which the browser downloads once and keeps:

<svg class="ggds-icon" aria-hidden="true" focusable="false"><use href="/ggds/icons/sprite.svg#download"/></svg>

Do

  • Write "Download the form" next to the download icon.
  • Keep to a few icons on a page.

Don't

  • Make a button that is only an icon, except search and menu in the header.
  • Use an icon to mean two different things.

Accessibility

What GGDS does

  • Icons take the colour of the text around them (currentColor), so they keep its contrast in every theme and in Windows high contrast mode.
  • svg(), icon(), {% ggds_icon %} and ggds_icon() hide icons from screen readers (aria-hidden="true") and keep them out of the tab order (focusable="false"), because the words beside them already say it.
  • Every icon is drawn with a 2px line on a 24px grid, so it stays clear at small sizes and when zoomed.

What you need to do

  • Put words next to every icon.
  • If an icon really must stand alone, give it a name: svg(download, { label: 'Download' }), or role="img" aria-label="Download" on the <svg>. In a button or link, put the name on the button or link instead.
  • Keep an icon in a link or button inside its target, so the whole thing is at least 44px tall to press (WCAG 2.5.8).
