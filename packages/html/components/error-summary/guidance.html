A box at the top of the page that lists every problem after a form is submitted.

When to use

  • After someone submits a form with problems.

When not to use

  • Before someone has submitted the form.
  • For messages that are not errors. Use a notice.

How to use

  • Use the same words as the message next to each field.
  • Link each item to its field.
  • Start the page title with "Error: " while it shows.
  • Add data-ggds-module="error-summary": with the GGDS script, the page moves to the summary when it loads.

Accessibility

What GGDS does

  • It has role="alert", so screen readers announce it even without JavaScript.
  • With the GGDS script it takes focus when the page loads, and each link moves focus to its field with the question in view.

What you need to do

  • List every error, in the same words as the message next to each field, and link each one to its field.
  • Start the page <title> with "Error: " while it shows.
  • Put it at the top of the main content, before the form.
