An amount drawn as a bar, so people can compare rows of a table at a glance: a chart that is still a table.

When to use

  • In a table, to compare one amount across rows: rainfall by region, applications by office.
  • For how full something is, such as places left at a session.

When not to use

  • On its own, without the number in words next to it.
  • For progress through a task: use progress.
  • For data that needs a real chart, such as a trend over time: show the table, and a chart image with a text description.

How to use

  • Put the number in its own cell, then the meter in the next. The number is what people read; the bar is for comparing.
  • Use a native <meter> with min, max and value: no style attributes, so it works under a strict Content Security Policy.
  • Use the same max on every row, a round number just above the largest value, so the bars compare fairly.
  • Hide the meter from screen readers with aria-hidden="true": the number in the table says it already.
  • Say the unit in the table’s caption or column heading.

Do

  • Show the number next to every bar.
  • Use one scale for the whole table.

Don't

  • Start the scale above zero: it exaggerates differences.

Accessibility

What GGDS does

  • The meter is a native element, drawn in the institution’s colour, with no script.
  • In Windows contrast themes it keeps an outline.

What you need to do

  • Keep the number in text next to the meter (WCAG 1.1.1 and 1.4.1).
  • Hide the meter from screen readers, so the number is not read twice.
