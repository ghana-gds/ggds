Tables for data people need to compare, such as fees or opening hours.

When to use

  • For data with rows and columns.

When not to use

  • For page layout.

How to use

  • Give every table a caption.
  • Use header cells for column and row titles.
  • Right-align numbers (ggds-table__numeric).

Accessibility

  • Wrap it in ggds-table-wrap with role="region", tabindex="0" and aria-labelledby pointing at the caption. Wide tables then scroll inside the box, and keyboard users can scroll them.
