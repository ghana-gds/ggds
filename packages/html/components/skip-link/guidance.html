A "Skip to main content" link that appears when someone presses Tab.

When to use

  • On every page.

When not to use

  • Pointing anywhere other than the main content.

How to use

  • Make it the first thing on the page.
  • Point it at your main content: <main id="main" tabindex="-1">.

Accessibility

  • It lets keyboard and screen reader users jump straight past the banner and menu.
