A "Skip to main content" link that appears when someone presses Tab.

When to use

  • On every page. Without it, keyboard users must Tab through the banner, header and menu on every page before reaching the content (WCAG 2.4.1).

When not to use

  • Pointing anywhere other than the main content.
  • More than once on a page.

How to use

  • Make it the first element in <body>, before the banner.
  • Point it at your main content: <main id="main" tabindex="-1">. The tabindex="-1" lets focus move to <main>, so the next Tab starts from the content, not from the top of the page.
  • Keep the words "Skip to main content".
  • Give <main> the class ggds-main. It removes the focus outline from <main> itself.
  • Check it on every page template: load the page, press Tab once, then Enter.

Do

  • Use the same skip link on every page.

Don't

  • Hide it with display: none; keyboard and screen reader users could not reach it.
  • Put the id="main" on more than one element.

Accessibility

What GGDS does

  • It is moved off screen, not hidden, so it stays in the Tab order and screen readers can always find it.
  • When it has focus it appears at the top left, above everything else, in bold dark text on gold.

What you need to do

  • Make it the first element in <body>.
  • Point it at <main id="main" tabindex="-1">, so focus really moves past the banner and menu.
  • Test it with a keyboard after any change to the page layout.
