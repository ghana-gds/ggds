A search box that keeps the search, a count, results people can scan, and help when nothing is found.

When to use

  • For your website's search page, and for any long list people search: licensed providers, laws, tenders, news.

How it works

  1. The search box at the top, still holding what people searched for, so they can change it.
  2. A count: "24 results for courier licence".
  3. Results: each a heading that links to the page, one line from it, and a tag for its type or status.
  4. Pagination at the end, keeping the search in every link.
  5. No results: say so, repeat the search, and suggest what to try next, including how to ask a person.

Details

  • Use a GET form, so every search has an address people can share and bookmark. With Django, {% ggds_pagination page_obj %} keeps the search.
  • Put the search in the page title: "courier licence – Search – PCSRC".
  • Show 10 to 20 results a page. Order them by what people most likely want, not by date alone.

Accessibility

  • Give the search box a visible label, or a hidden one when the page's heading already says "Search".
  • Make the result count the first thing after the search box, so screen reader users hear it straight away.
  • Results are a list of headings, so people can move from one to the next.
