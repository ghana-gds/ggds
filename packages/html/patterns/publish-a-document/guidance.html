Pages for news, public notices and publications that say what they are and when they were published, put the content in HTML, and label every download.

When to use

  • For a news story, a press release, a public notice, a consultation, a report, a law or a form people download.

How it works

  1. Breadcrumbs show which list the page belongs to, such as News or Publications.
  2. A tag says what type of page it is: "Press release", "Public notice", "Report". Use the same words everywhere.
  3. The heading says what it is about in plain words, not a reference number or a date.
  4. The date it was published, and the date it was last changed if it has changed.
  5. A summary of one or two sentences: what it is and who it affects.
  6. The content, written on the page in the prose component.
  7. Downloads, each with its file type and size.

HTML first

  • Put the content on the page, not only in a PDF. A web page is quicker to load, cheaper on mobile data, easier to read on a small phone, and works with screen readers and translation tools.
  • Offer a PDF as well when people need to print it, sign it or keep an official copy.
  • Never publish a scanned image of a letter or notice on its own. People cannot search it, copy from it or read it with a screen reader. Type the text on the page too.
  • Do not put a notice only on social media or in a newspaper. Publish it on your website, so there is one place people can check that it is real.

Downloads

  • Write the file type and size after the title, in the link text: "Annual report 2025 (PDF, 1.2 MB)". People on slow or costly data can then decide whether to download it.
  • Give the number of pages for long documents.
  • Keep files small. Compress images in a PDF, and split a very large report into parts.
  • Name the file the way people would: annual-report-2025.pdf, not scan_0034.pdf.
  • Use PDF for documents and ODS or CSV for data. Do not ask people to download a Word file to read it.

Dates and changes

  • Write dates in full: 3 November 2026. Not 03/11/26, which people read in different ways.
  • When you change a page, say what changed and when. If a notice has been withdrawn, keep the page and say so at the top with a notice, so links to it still work.
  • For a consultation or a tender, show the closing date near the top.

Accessibility

  • Mark up dates with <time datetime="2026-11-03">.
  • Make PDFs accessible too: real text, headings, a title and a language. Check them before you publish.
  • Give images in a story alternative text that says what they show. Leave it empty for decoration.
